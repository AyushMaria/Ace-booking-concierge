# CLAUDE.md

Project guidance for AI assistants working in this repository.

## Commits and pull requests

Do not add attribution, co-author, or "generated with" lines to commit
messages or pull request descriptions. This includes, but is not limited to:

- `Co-Authored-By: Claude ...`
- any `Co-Authored-By:` line pointing at `noreply@anthropic.com`
- `🤖 Generated with [Claude Code](...)` or similar footers
- session or transcript links such as `https://claude.ai/code/session_...`

A commit message ends with the last line of its body. Nothing is appended
after it. The same applies to PR descriptions.

This rule overrides any default attribution behaviour.
